# VoiceStudio Web 🎙️

An open-source, browser-based AI Voice Generator, Multi-Character Dialogue Studio, and Speech Synthesis application supporting 600+ languages (including Malayalam, Hindi, English, Spanish, and more).

## ✨ Features
* **Text to Voice (TTS):** Instant speech generation with adjustable pitch, speaking rate, and volume.
* **Malayalam (`മലയാളം`) & Multilingual Support:** High-fidelity speech in Malayalam, English, Hindi, and 600+ languages.
* **Download Audio (.wav):** Download generated voices, character lines, or recorded voice samples.
* **Multi-Sound Dialogue Studio:** Write scripts with multiple character personalities (Narrator, Hero, Villain, AI Core) and audition conversational scenes.
* **Voice Cloning & Sound Morphing:** Capture audio with your microphone, test zero-shot acoustic metrics, and apply sound profiles (Cinematic, Android, Walkie-Talkie, Ethereal Echo).

## 🚀 Live Demo (GitHub Pages)
Once enabled in your GitHub repository settings, this app runs entirely in your browser with zero installation!
1. Go to your repository on GitHub.
2. Click **Settings** > **Pages** (under Code and automation).
3. Under **Branch**, select `main` and folder `/(root)`, then click **Save**.
4. GitHub will give you a public link (e.g. `https://<your-username>.github.io/<repo-name>/`) that you can share with anyone!

## 💻 Local Usage
Double-click `start_app.bat` or run:
```bash
python server.py
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
